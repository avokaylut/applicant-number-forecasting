# Валидация и воспроизводимость

Для каждого проверяемого сезона модель обучается только на более ранних годах. Итоговый прогноз на 2024 год использует историю 2014–2023 годов.

## Временное разбиение

- Основная версия: 2018, 2019, 2021, 2022 и 2023; отдельно 2020.
- Версия v3: те же годы и дополнительно 2017.
- Сравнивать средние оценки двух версий нужно на одинаковом наборе лет.
- Среднее по годам — макросреднее RMSLE, а не RMSLE всех дней вместе.

Исторические сезоны использовались при выборе моделей и настроек. Поэтому эти оценки характеризуют ретроспективную валидацию, а не независимый финальный тест. В 2023 году v3 уступает основной версии.

## Признаки

Календарные признаки известны заранее. Исторические признаки CatBoost для каждого года рассчитываются только по предыдущим сезонам. Сглаживание использует соседние прогнозы, а не фактические значения прогнозируемого года.

Статусы заявлений и сведения о включении в конкурсные списки не участвуют в моделях. Прямого использования тестовых целей в проверенных режимах не обнаружено.

## Запуск и тесты

Рекомендуемый запуск — через `scripts/run.py`: он проверяет полные сезоны, уникальность дат и допустимость дневных количеств. При отдельном вызове `predict` нужно самостоятельно обеспечить разделение обучающих и тестовых лет.

Пять тестов на синтетических данных проверяют календарь, RMSLE, временные ограничения, исторические признаки и независимость прогноза от тестовых целей.

Обе основные версии прошли полный запуск на Windows с Python 3.11.4. Повторные запуски в том же окружении дали одинаковые CSV прогнозов. Версии библиотек зафиксированы в `requirements.txt`; чистая установка и запуск на других ОС отдельно не проверялись.
