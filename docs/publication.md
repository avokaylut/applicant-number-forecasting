# Материалы проекта

В репозитории находятся две версии решения, инструкции запуска, тесты и иллюстрации результатов.

Исходные таблицы, дневные агрегаты и CSV прогнозов хранятся локально и исключены из Git через `.gitignore`. Скриншот командного результата и график валидации находятся в `docs/images/`.

Соревнование закрытое. Для работы с исходными данными необходим доступ к материалам соревнования; их распространение регулируется его условиями.
