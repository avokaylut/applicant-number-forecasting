# Условия публикации

Текущий статус: **private; разрешение на публичное распространение не установлено**.

Правила закрытого соревнования по адресу https://www.kaggle.com/competitions/forecasting-the-number-of-applicants/rules не удалось получить при проверке 26 ноября 2026 года. Недоступность страницы не означает разрешение на публикацию.

Перед переходом в public необходимо:

1. Получить применимую редакцию правил и подтверждение организаторов относительно командного кода, описания признаков и достижений.
2. Согласовать публикацию кода с командой; не приписывать компоненты конкретному участнику без подтверждения.
3. Отдельно согласовать любые данные, агрегаты, графики по ним и скриншот закрытого лидерборда. По умолчанию они остаются локальными.
4. Проверить весь состав файлов и историю Git, включая старые ветки. Удаление из рабочей папки не удаляет данные из истории.
5. После согласования выбрать лицензию для тех материалов, на которые есть права. До этого открытая лицензия не добавляется.

В приватный репозиторий переносится только код и документация, явно запрошенные владелицей. Данные и производные результаты не переносятся даже в приватный GitHub. Приватность не заменяет разрешение на распространение.
