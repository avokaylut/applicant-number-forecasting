# Данные

Архив содержит три таблицы XLSX за 2014–2023 годы. Исходные файлы не включены в репозиторий.

| Таблица | Поля | Использование |
|---|---|---|
| Зарегистрированы (2014–2023) | `abitur_kod`, `zayav_type_kod`, `zayav_type_name`, `priem_doc_type_kod`, `priem_doc_type_name`, `reg_ts` | Только `reg_ts` для дневных количеств |
| Включены в КС (2014–2023) | Те же поля, дополнительно `ob_osnova_kod`, `ob_osnova_name` | Не используется |
| Статусы заявлений (2014–2023) | `abitur_kod`, `zayav_status_kod`, `zayav_status_name`, `priem_doc_type_name`, `ts_reg`, `ts_reject` | Не используется |

`abitur_kod` — идентификатор абитуриента; в моделях он не используется. Строки с идентификаторами, исходный архив и дневные агрегаты исключены из GitHub. В README включены скриншот лидерборда и график исторической валидации.

Подготовленный локальный CSV:

| Поле | Значение |
|---|---|
| `date` | Дата без времени: ровно 20 июня — 31 августа каждого года 2014–2023 |
| `target` | Количество строк регистраций за день, целое неотрицательное |
| `in_submission_window` | 1 для всех подготовленных строк; совместимость с clean-loader |

Итого 730 дат, по 73 на год. Считаются строки регистраций по дате, без дедупликации по абитуриентам. Отсутствующие даты заполняются нулями.

`scripts/run.py` проверяет границы сезонов, уникальность дат и допустимость значений. Для запуска используется история 2014–2023 годов.

В архиве нет доступных фактических целей 2024 года и шаблона отправки. Выходной CSV имеет поля `date,forecast`; сверка с официальным sample submission не выполнена.
