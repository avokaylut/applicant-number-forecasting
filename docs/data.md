# Контракт данных

Архив изучен локально без вывода значений идентификаторов. Он содержит три XLSX и служебные записи `__MACOSX`. Эти файлы не входят в репозиторий.

| Таблица | Поля | Использование |
|---|---|---|
| Зарегистрированы (2014–2023) | `abitur_kod`, `zayav_type_kod`, `zayav_type_name`, `priem_doc_type_kod`, `priem_doc_type_name`, `reg_ts` | Только `reg_ts` для дневных количеств |
| Включены в КС (2014–2023) | Те же поля, дополнительно `ob_osnova_kod`, `ob_osnova_name` | Не используется |
| Статусы заявлений (2014–2023) | `abitur_kod`, `zayav_status_kod`, `zayav_status_name`, `priem_doc_type_name`, `ts_reg`, `ts_reject` | Не используется |

`abitur_kod` — идентификатор записи об абитуриенте; нельзя считать его безопасным для распространения только из-за отсутствия ФИО. Строки с идентификаторами, исходный архив и дневные агрегаты исключены из GitHub. В README включены скриншот лидерборда и график исторической валидации.

Подготовленный локальный CSV:

| Поле | Значение |
|---|---|
| `date` | Дата без времени: ровно 20 июня — 31 августа каждого года 2014–2023 |
| `target` | Количество строк регистраций за день, целое неотрицательное |
| `in_submission_window` | 1 для всех подготовленных строк; совместимость с clean-loader |

Итого 730 дат, по 73 на год. Группировка следует `read_history(..., raw_path=...)` расширенного исходника. Дедупликация по абитуриентам или заявлениям намеренно не выполняется: она изменила бы исходную цель. Полнота исходного журнала и точная семантика повторных строк требуют подтверждения организаторов.

Неполные сезоны, отрицательные/нечисловые значения, дубликаты дат или добавленные фактические значения 2024 года должны быть отклонены обёрткой запуска. Исходный clean-loader проверяет число строк, но сам по себе не гарантирует правильные границы сезона; используйте `scripts/run.py`.

В архиве нет доступных фактических целей 2024 года и шаблона отправки. Формат `date,forecast` воспроизводит исходники; независимая проверка по официальному sample submission пока невозможна.
